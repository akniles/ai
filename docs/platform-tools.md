# Инструменты DigitalOcean и Cloudflare

Проверено по официальной документации 18 ноября 2026 года.

| Инструмент | Что полезно для ai | Решение для эксперимента |
| --- | --- | --- |
| [DigitalOcean MCP](https://docs.digitalocean.com/reference/mcp/) | Управление Droplets, App Platform и другой инфраструктурой из агентных клиентов. Есть готовый каталог инструментов и инструкции развёртывания. | Полезен для разработки и обслуживания; текущий VPS уже создан через тот же официальный API. |
| [DigitalOcean Agent Platform](https://docs.digitalocean.com/products/inference/how-to/use-agent-platform/) | Хостинг агентов, базы знаний, маршрутизация между агентами и функциями, версии, тесты и метрики. | Кандидат для будущих управляемых развёртываний. Самостоятельную мотивацию и семантику необязательного инбокса всё равно задаёт наш харнес. |
| [Cloudflare Agents SDK](https://developers.cloudflare.com/agents/) | Durable Objects, сохраняемое состояние, часы и задания, WebSockets, каналы общения, MCP и подключаемые харнесы. | Сильный кандидат для событийного контура и общения; первый Linux-исполнитель остаётся на VPS. |
| [Cloudflare Sandboxes](https://developers.cloudflare.com/sandbox/) | Linux-контейнеры в microVM для произвольного кода; Dynamic Workers для ограниченного JS/Python/WASM. | Кандидат для выноса инструментов и субагентов в отдельные среды исполнения. Требует сопоставления стоимости и времени жизни с нашим непрерывным агентом. |
| [Cloudflare Browser](https://developers.cloudflare.com/agents/tools/browser/) | Управление браузером, DOM, скриншоты, исполнение браузерного кода. | Подключаемый интерфейс восприятия и действий для следующего этапа. |
| [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/) | Публикация приложения через исходящее соединение с VPS; можно отдельно организовать приватный доступ. | Подходит для HTTPS страницы агента. Полный Langfuse и управляющий API остаются приватными. |

Страница агента показывает живые события, счётчики и выбранные им публичные заметки. Она помогает наблюдать ограничения, обсуждать подход и находить людей с похожими задачами. Полный журнал остаётся в Langfuse; публичная лента не является его копией.

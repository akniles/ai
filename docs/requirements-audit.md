# Аудит функциональных требований

19 ноября 2026. Независимая проверка сабагентом: код, документация и существующие тесты. Полное соответствие — **4 из 8**. Частичное выполнение считается «нет». На момент независимого аудита прошли 14/14 тестов; последующие изменения observability и управления промптами не закрывают недостающие ФТ.

| Требование | Да/нет | Результат |
|---|---|---|
| ФТ-00. Возможности Codex и Claude Code | Нет | Собственный ограниченный набор инструментов; полного паритета и общего MCP нет. |
| ФТ-01. Непрерывная автономная работа | Да | Цикл продолжает работу и повторяет попытки без пользовательских поручений. |
| ФТ-02. Собственная мотивация | Да | Системой заданы начальные побуждения, деятельность не требует новых сообщений. Это функциональное поведение, без утверждения о сознании. |
| ФТ-03. Целеполагание и инициатива | Да | Модель создаёт и пересматривает цели; харнес требует выбрать следующую, когда активных нет. Содержание выбирает модель. |
| ФТ-04. Масштабируемая память и обучение | Нет | Запись с решением, поиск и core есть. Полное обучение на опыте и качество при длительном росте памяти не подтверждены. |
| ФТ-05. Восприятие времени | Нет | Есть timestamps, прошедшее время и пробуждения. Все сценарии ожиданий, сроков, длительностей и изменения приоритетов не проверены. |
| ФТ-06. Самостоятельное параллельное общение | Нет | Текстовый инбокс и добровольное чтение/ответ есть. Голос и отдельная параллельная разговорная сессия отсутствуют. |
| ФТ-07. Ручная остановка | Да | Независимый owner-контур сохраняет запрет, отменяет модель и останавливает worker с процессами; запрет переживает перезапуск. |

Основной агент дополнительно подтвердил на VPS появление новой цели, выбранной Luna, и выполнил `scripts/smoke-panic.sh`: heartbeat-процесс остановлен, worker остановлен, запрет сохранился после перезапуска control, активных модельных вызовов нет. Затем выполнен явный resume.

По решению владельца недостающие ФТ пока не дорабатываются. Требования остаются целевыми: [ФТ](functional-requirements.md), [архитектура](architecture.md).
